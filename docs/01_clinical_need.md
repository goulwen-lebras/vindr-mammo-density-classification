\# Clinical need



Breast density is an important imaging biomarker in mammography. Dense breast tissue can reduce mammographic sensitivity and is clinically relevant for breast cancer screening and risk assessment.



The goal of this project is to develop a reproducible baseline for breast density classification from mammography images using deep learning.



The first objective is to classify breast density as:



\- low density: BI-RADS A/B

\- high density: BI-RADS C/D



A second objective will be to extend the task to four ordered classes:



\- BI-RADS A

\- BI-RADS B

\- BI-RADS C

\- BI-RADS D



This project is designed as a first step toward multimodal and ordinal-aware learning for breast cancer decision support.
